# Plan 01-03: Topology Chain Parser, Premises Ingestion, Critical Facilities, and Ingestion Verification

## Objective
Stream and anonymize all 117,642 premises from `Customer_Clip.dbf`, parse all 117,599 lines of `matched_upstream.txt` into ordered device dependency chains, load rounded critical facilities (hospitals, fire stations, ambulances), and run full verification checks.

## Context
- `matched_upstream.txt` maps premise numbers directly to upstream isolating equipment and circuit breakers.
- Raw equipment serial numbers must be mapped to customer-safe labels ("Upstream Recloser 1", "Upstream Fuse 2", "Circuit Breaker").
- Public critical facilities must have coordinates rounded to ~1 km (~0.01 degrees) to prevent exposing precise facility locations while preserving operational proximity analysis.

## Tasks
1. **Ingest and Anonymize Premises (`ingest/ingest_premises.py`)**:
   - Stream `Customer_Clip.dbf`.
   - Calculate `premise_key = hash(salt + premise_nu)`.
   - Store only `premise_key`, `circuit_id`, `transformer_id`, `is_critical_tier` (1 if `critical_c != 'N/A'` or `special_op != ''` else 0), `lat`, `lon`.
   - Drop all personal names, account IDs, addresses, and street names.
2. **Parse Upstream Topology Chains (`ingest/ingest_topology.py`)**:
   - Stream `matched_upstream.txt`.
   - Tokenize upstream devices: `eo_power_xfrmr_inst`, `eo_isolating_eqpt_inst` (Recloser, Fuse, Switch), and `eo_circuit`.
   - For each premise, generate step-ordered rows in `topology_edges` with customer-facing anonymous labels.
3. **Ingest Public Critical Facilities (`ingest/ingest_facilities.py`)**:
   - Load `Hospitals_Medic_Pairwis_Clip.dbf`, `Fire_Stations_E_Pairwis_Clip.dbf`, and `Ambulance_Servi_Pairwis_Clip.dbf`.
   - Round latitude and longitude to 2 decimal places (~1.1 km resolution).
4. **Build Ingestion Verification Suite (`tests/test_ingestion.py`)**:
   - Assert `damage_events` count == 1,659.
   - Assert `premises` count == 117,642.
   - Assert `topology_edges` covers 117,599 premises.
   - Assert no unhashed premise numbers exist in any SQLite table.
   - Assert execution time < 90 seconds.

## Verification
- Run `python -m unittest tests/test_ingestion.py` and confirm all assertions pass.
- Execute sample SQL query joining premise -> circuit -> historical damage -> upstream devices in < 5ms.
