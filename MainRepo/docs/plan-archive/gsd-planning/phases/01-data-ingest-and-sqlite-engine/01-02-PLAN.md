# Plan 01-02: ARCOS Damage Ingestion, Storm Tagging, and Labor Workbook Extraction

## Objective
Extract, clean, and load historical ARCOS damage records (tagging the Feb 2025 Winter Storm and Sept 2024 Event) and parse all sheets of `Install_Labor_HackOHIO.xlsx` into normalized SQLite tables.

## Context
- ARCOS damage records contain 1,659 entries with exact report times, coordinates, circuits, asset types, and access difficulty flags.
- `Install_Labor_HackOHIO.xlsx` contains:
  - 17 CU Group categories with average install and removal hours.
  - Labor adders (Difficult Location 0.5h, Backyard 0.5h, Remote Access 0.5h or 1.312h, Manual Dig 1.5h, Difficult Excavation 4.0h).
  - Indirect Labor Multiplier (ILM) = 4.5.
- Asset types in ARCOS must be mapped directly to labor CU groups and structural components.

## Tasks
1. **Ingest ARCOS Damage Records (`ingest/ingest_damage.py`)**:
   - Stream `arcos_prod_damage_09_28_Clip.dbf` into `damage_events`.
   - Compute storm cluster tagging:
     - `winter_storm_2025`: Report dates 2025-02-13 through 2025-02-17 (1,223 events).
     - `helene_storm_2024`: Report dates 2024-09-27 through 2024-09-30 (173 events).
     - `other_events`: Remaining dates.
   - Sanitize and normalize circuits (`CIR2`, `CIR10`, `CIR72`, etc.).
2. **Ingest Labor Reference Workbook (`ingest/ingest_labor.py`)**:
   - Parse `Install_Labor_HackOHIO.xlsx` using `openpyxl`.
   - Populate `labor_codes` with CU groups (`ARM`, `POL`, `BKT`, `REC`, `SWI`, `XCO`, etc.) and their calculated average install and removal hours.
   - Populate `labor_adders` with access constraints and excavation adders.
   - Record the constant Indirect Labor Multiplier (4.5) into system configuration metadata table.
3. **Build Damage-to-Labor Mapping Table (`ingest/mapping.py`)**:
   - Map ARCOS `Asset_Type` to CU labor codes:
     - `Pole` -> `POL` (medium pole avg: 2.50h install / 0.93h remove)
     - `Fuse Bank` -> `XCO` (0.256h install / 0.128h remove)
     - `Transformer` -> `XFR` (avg ~1.25h install / 0.88h remove)
     - `Recloser Bank` -> `REC` (0.573h install / 0.525h remove)
     - `Switch` -> `SWI` (1.758h install / 1.010h remove)
     - `primary` / `secondary` conductor -> `ARM` + `INS` + `DEC` combined wire replacement allowance.

## Verification
- Verify `damage_events` row count equals 1,659.
- Verify `winter_storm_2025` has >1,200 tagged records.
- Verify `labor_codes` and `labor_adders` match the Excel workbook exactly.
